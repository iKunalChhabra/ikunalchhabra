### Hi, I'm Kunal.

I'm an AI & Data Engineering Lead based in Bengaluru, India. For the past 8+ years I've been building data platforms, streaming pipelines, and AI systems that run quietly at scale — the kind of infrastructure you only notice when it's missing.

Lately my work has centered on RAG systems and database internals. I write most things in TypeScript, Python, and Go.

Outside of work I like rebuilding things from first principles to understand how they actually work: [sqllite-rust](https://github.com/iKunalChhabra/sqllite-rust) is a SQLite-like database written from scratch, and [go-z](https://github.com/iKunalChhabra/go-z) is a schema-first validation library for Go. Most of my day-to-day work lives in private repos.

More about my work at [ikunalchhabra.com](https://ikunalchhabra.com). The best way to reach me is email.
